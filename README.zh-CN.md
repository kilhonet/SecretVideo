## 简介

SecretVideo 是一款为视频网站打造的浏览器式播放器。在首页选择常用网站即可直接打开；把视频切换到全屏时，它会变成一个小小的**画中画（PIP）窗口**，让你一边做别的事一边继续观看。

当正在观看的视频可以保存时，地址栏旁会出现**下载按钮**。点一下即可按你选择的格式和画质保存——原始文件、MP4 或 MP3。需要登录的网站同样支持：在 SecretVideo 内登录一次，登录状态会一直保留。

广告拦截默认开启，按 `Ctrl+P` 还能把当前整个页面保存为图片。

## 主要功能

- **网站首页** — YouTube、Twitch、TikTok、CHZZK、Netflix、TVING、Wavve、Watcha、Coupang Play 等常用网站集中在一处，列表可自由添加和编辑。
- **全屏自动切换为画中画** — 视频进入全屏后自动变成置顶小窗口，可随意拖动，也可从边缘调整大小。
- **只在可用时出现的下载按钮** — 当可保存的视频准备好后按钮才会滑出；广告和直播不会出现。
- **格式与画质随你选** — 原始 / MP4 / MP3，720p / 1080p / 最高画质。
- **下载列表窗口** — 缩略图与进度一目了然，下载完成时弹出 Windows 通知。
- **广泛的网站支持** — 内置广泛使用的下载引擎（yt-dlp）；引擎不认识的网站，SecretVideo 会自行找到正在播放的文件并保存。
- **保持登录状态** — 在 SecretVideo 内登录网站后，会员专属视频也能观看和保存。
- **广告拦截** — 内置 uBlock Origin Lite，可在菜单中开启或关闭。
- **整页截图** — `Ctrl+P` 将整个页面（包括需要滚动才能看到的部分）保存为 PNG。
- **记住窗口状态** — 主窗口的位置/大小/最大化状态、画中画窗口的位置和大小、下载列表窗口的位置。

## 使用方法

### 快速上手

1. 启动 SecretVideo，出现**网站首页**，点击想去的网站。
2. 像在普通浏览器中一样浏览网站并播放视频。
3. 如果视频可以保存，地址栏右侧会出现**下载按钮**（↓）。点击后立即开始保存。
4. **下载列表**窗口会自动打开并显示进度。完成后弹出 Windows 通知，点击通知即可打开保存文件夹。

默认保存文件夹是电脑的**下载**文件夹。可在菜单（⋮）→ **文件夹设置**中更改，或用**打开文件夹**直接打开。

### 窗口布局

| 控件 | 作用 |
|---|---|
| ◀ ▶ | 后退 / 前进 |
| ⟳ / ✕ | 刷新（页面加载中时为停止） |
| 地址栏 | 输入网址直接跳转；输入关键词则进行搜索 |
| ↓ | 下载按钮——只在可保存的视频准备好时出现 |
| ⋮ | 菜单 |

窗口标题会跟随页面标题。即使网站试图打开新窗口，SecretVideo 也会在当前窗口中打开。

### 常见场景

**把 YouTube 视频保存为 MP3**
菜单 → **格式设置 → MP3**，然后在视频页面点击下载按钮。只下载音频并转换为 MP3。画质设置对 MP3 无影响。

**想要能在电视或其他设备上播放的文件**
选择**格式设置 → MP4**。在同一分辨率下，SecretVideo 会优先选择兼容性好的 H.264 格式，减少在普通播放器或电视上打不开的情况。**原始**则按网站提供的文件原样保存（必要时合并为 MP4）。

**想节省空间 / 想要最高画质**
在**下载画质**中选择 **720p**、**1080p**（默认）或**最高画质**。720p 和 1080p 表示"最高到该分辨率"：若没有该分辨率，则使用次一级分辨率。

**下载经常中断或失败**
试试**下载速度 → 稳定模式**。它逐段下载，在网络不稳定时更可靠。如果你的网络很快，**高速模式**（多段同时下载）会快得多。默认是**标准模式**。

**需要登录的会员视频**
在 SecretVideo 内像平时一样登录该网站。登录状态会保留，之后会员视频可直接播放；只要视频可保存，下载按钮就会出现。

**下载整个播放列表**
在 YouTube 播放列表页面点击下载按钮，会依次下载整个列表。例外是自动生成的**合辑 / 电台**列表：只下载当前观看的视频。

**滚动切换视频的网站（TikTok 等）**
即使页面地址不变，SecretVideo 也能识别正在播放的视频。滚动到喜欢的视频后直接点击下载按钮即可。

**CHZZK、Twitch 等直播网站**
回放和剪辑可以保存。**直播无法保存**，也不会出现下载按钮。

**一边工作一边看（画中画）**
把视频切换到**全屏**，SecretVideo 会自动变成置顶的小画中画窗口。
- **拖动**窗口即可移动。
- 抓住**边缘**即可调整大小。
- **右键**菜单：返回普通窗口 / 开启或关闭置顶 / 退出。
- 网站退出全屏后，窗口会恢复到原来的大小和位置。
- 画中画窗口的位置和大小会被记住，下次沿用。
- 如果不需要此功能，关闭菜单 → **进入全屏时启用 PIP** 即可。之后全屏会像普通浏览器一样占满整个显示器。

**把整个页面保存为图片**
按 `Ctrl+P`。**整个页面**——不只是可见部分，还包括需要滚动的部分——会以 `SecretVideo-001.png` 之类的名称保存到保存文件夹，并弹出通知。适合保存帖子、评论或字幕画面。

**广告碍事 / 广告拦截导致网站异常**
广告拦截（uBlock Origin Lite）默认开启。如果某个网站运行不正常，可在菜单 → **扩展**中暂时关闭。

**管理已下载文件（下载列表窗口）**
随时可从菜单 → **下载列表**打开。每行显示缩略图、标题、来源和状态（空闲 → 分析 → 接收 → 转换 → 完成），行背景表示进度。
- **双击**：打开已下载的文件
- **Delete 键**：从列表中移除
- **右键**：前往来源 / 打开文件夹 / 查看日志 / 删除
- 关闭窗口或按 `ESC` 只是隐藏窗口，下载会继续。

**同一视频下载两次**
若已存在同名文件，不会覆盖，而是加上 `(1)`、`(2)` 之类的编号。

**编辑网站首页**
用首页的 **Edit** 添加或删除网站，用 **Reset** 恢复默认列表。只保留常用网站，启动会更快。

## 设置

没有单独的设置窗口；所有设置都在菜单（⋮）中修改并自动保存。

| 菜单 | 内容 | 默认值 |
|---|---|---|
| 文件夹设置 / 打开文件夹 | 文件保存位置 | 下载文件夹 |
| 格式设置 | 原始 / MP4 / MP3 | 原始 |
| 下载速度 | 稳定 / 标准 / 高速 | 标准 |
| 下载画质 | 720p / 1080p / 最高画质 | 1080p |
| 下载列表 | 显示或隐藏列表窗口 | 开始下载时自动打开 |
| 进入全屏时启用 PIP | 全屏切换为画中画窗口 | 开 |
| 扩展 | 广告拦截开/关 | 开 |

界面语言跟随 Windows 显示语言（韩语 → 韩语，其他 → 英语）。
