## 概要

SecretVideo は動画サイトのために作られたブラウザー型プレーヤーです。ホーム画面でよく使うサイトを選べばすぐに開き、動画を全画面にすると小さな **PIP ウィンドウ**に切り替わるので、他の作業をしながら視聴を続けられます。

見ている動画が保存できるときは、アドレスバーの横に**ダウンロードボタン**が現れます。クリック一つで、オリジナル・MP4・MP3 の中から選んだ形式と画質で保存できます。ログインが必要なサイトも、SecretVideo の中で一度ログインしておけばそのまま利用できます。

広告ブロックは最初からオンになっており、`Ctrl+P` を押すだけで表示中のページ全体を画像として保存できます。

## 主な機能

- **サイトのホーム画面** — YouTube、Twitch、TikTok、CHZZK、Netflix、TVING、Wavve、Watcha、Coupang Play など、よく使うサイトを一か所に。一覧は自由に追加・編集できます。
- **全画面 → PIP に自動切り替え** — 動画を全画面にすると、常に手前に表示される小さなウィンドウになります。ドラッグで移動、端をつかんでサイズ変更できます。
- **使えるときだけ現れるダウンロードボタン** — 保存できる動画の準備ができるとボタンがスライドして現れます。広告やライブ配信には現れません。
- **形式と画質を選択** — オリジナル / MP4 / MP3、720p / 1080p / 最高画質。
- **ダウンロード一覧ウィンドウ** — サムネイルと進行状況をひと目で。完了すると Windows の通知が届きます。
- **幅広いサイトに対応** — 広く使われているダウンロードエンジン（yt-dlp）を内蔵。エンジンが知らないサイトでは、再生中のファイルを SecretVideo 自身が見つけて保存します。
- **ログイン状態を維持** — SecretVideo の中でサイトにログインしておけば、会員限定の動画も視聴・保存できます。
- **広告ブロック** — uBlock Origin Lite を内蔵。メニューからオン/オフできます。
- **ページ全体のキャプチャ** — `Ctrl+P` でスクロールの先まで含めたページ全体を PNG で保存します。
- **ウィンドウの状態を記憶** — メインウィンドウの位置・サイズ・最大化状態、PIP ウィンドウの位置とサイズ、ダウンロード一覧の位置を記憶します。

## 使い方

### はじめての使い方

1. SecretVideo を起動すると**サイトのホーム画面**が表示されます。見たいサイトをクリックします。
2. 普通のブラウザーと同じようにサイトを見て回り、動画を再生します。
3. 動画が保存できる場合、アドレスバーの右に**ダウンロードボタン**（↓）が現れます。クリックするとすぐに保存が始まります。
4. **ダウンロード一覧**ウィンドウが自動で開き、進行状況を表示します。完了すると Windows の通知が届き、通知をクリックすると保存フォルダーが開きます。

保存先は初期設定では PC の**ダウンロード**フォルダーです。メニュー（⋮）→ **フォルダー設定**で変更でき、**フォルダーを開く**ですぐに開けます。

### 画面構成

| 部品 | 役割 |
|---|---|
| ◀ ▶ | 戻る / 進む |
| ⟳ / ✕ | 再読み込み（読み込み中は停止） |
| アドレスバー | URL を入力するとそのページへ、URL 以外の言葉を入力すると検索結果へ |
| ↓ | ダウンロードボタン — 保存できる動画の準備ができたときだけ表示 |
| ⋮ | メニュー |

ウィンドウのタイトルは表示中のページタイトルになります。サイトが新しいウィンドウを開こうとしても、SecretVideo は現在のウィンドウ内で開きます。

### こんなときは

**YouTube の動画を MP3 で保存したい**
メニュー → **形式設定 → MP3** を選び、動画ページでダウンロードボタンを押します。音声だけを取得して MP3 に変換し保存します。画質設定は MP3 には影響しません。

**テレビや他の機器でも再生できるファイルが欲しい**
**形式設定 → MP4** を選びます。同じ解像度なら互換性の高い H.264 形式を優先するので、標準プレーヤーやテレビで開けないトラブルが減ります。**オリジナル**はサイトが提供するファイルをそのまま（必要なら MP4 に結合して）保存します。

**容量を節約したい / 最高画質で保存したい**
**ダウンロード画質**で **720p**、**1080p**（初期値）、**最高画質**から選びます。720p・1080p は「最大でその解像度」という意味で、その解像度がなければ一つ下の解像度を取得します。

**ダウンロードがよく途切れる・失敗する**
**ダウンロード速度 → 安定モード**を試してください。動画を一区切りずつ順に取得するので、不安定な回線でも粘り強く動きます。逆に回線が速いなら**高速モード**（複数の区切りを同時取得）のほうがずっと速くなります。初期値は**標準モード**です。

**会員限定・ログインが必要な動画**
SecretVideo の中でそのサイトに普段どおりログインしてください。ログイン状態が保持されるので、以降は会員動画もすぐに再生でき、保存できる動画ならダウンロードボタンが現れます。

**再生リストをまとめて保存したい**
YouTube の再生リストのページでダウンロードボタンを押すと、リスト全体を順番に取得します。ただし自動生成される**ミックス / ラジオ**のリストは、今見ている動画一つだけになります。

**TikTok のようにスクロールで動画を切り替えるサイト**
ページの URL が変わらなくても再生中の動画を検知するので、スクロールして気に入った動画でそのままダウンロードボタンを押してください。

**CHZZK・Twitch のような配信サイト**
アーカイブとクリップは保存できます。**ライブ配信は保存できず**、ダウンロードボタンも現れません。

**動画を見ながら別の作業をしたい（PIP）**
動画を**全画面**にすると、SecretVideo が自動で常に手前に表示される小さな PIP ウィンドウになります。
- ウィンドウを**ドラッグ**して好きな場所へ移動します。
- **端**をつかんでサイズを変えます。
- **右クリック**メニュー：元のウィンドウに戻る / 常に手前に表示のオン・オフ / 終了。
- サイト側で全画面を解除すると、元のウィンドウサイズと位置に戻ります。
- PIP ウィンドウの位置とサイズは記憶され、次回も同じ場所に表示されます。
- この動作が不要なら、メニュー → **全画面時に PIP を有効にする**をオフにしてください。普通のブラウザーと同じようにモニター全体を使います。

**表示中のページを丸ごと画像で残したい**
`Ctrl+P` を押すと、見えている部分だけでなく**ページ全体**（スクロールの先まで）が `SecretVideo-001.png` のような名前で保存フォルダーに保存され、通知が届きます。投稿・コメント・字幕画面の保管に便利です。

**広告が邪魔 / 広告ブロックのせいでサイトがおかしい**
広告ブロック（uBlock Origin Lite）は最初からオンです。特定のサイトが正しく動かない場合は、メニュー → **拡張機能**で一時的にオフにできます。

**保存したファイルの管理（ダウンロード一覧ウィンドウ）**
メニュー → **ダウンロード一覧**でいつでも開けます。各行にサムネイル・タイトル・出典・状態（待機 → 解析 → 受信 → 変換 → 完了）が表示され、行の背景が進行状況を表します。
- **ダブルクリック**：保存したファイルを開く
- **Delete キー**：一覧から削除
- **右クリック**：元のページへ / フォルダーを開く / ログを見る / 削除
- ウィンドウを閉じたり `ESC` を押したりしてもダウンロードは続き、ウィンドウが隠れるだけです。

**同じ動画を二度保存すると**
同じ名前のファイルがあれば上書きせず、`(1)`、`(2)` のように番号を付けて保存します。

**サイトのホーム画面を編集する**
ホーム画面の **Edit** でサイトを追加・削除し、**Reset** で初期の一覧に戻します。よく使うサイトだけを残しておくと、始めるのが速くなります。

### 著作権について

SecretVideo は、利用する権利のある動画を個人的に視聴・保管するためのツールです。各サイトの利用規約と著作権を守ってご利用ください。

## 設定

専用の設定画面はなく、メニュー（⋮）からそのまま変更します。すべての設定は自動的に保存されます。

| メニュー | 内容 | 初期値 |
|---|---|---|
| フォルダー設定 / フォルダーを開く | ファイルの保存先 | ダウンロードフォルダー |
| 形式設定 | オリジナル / MP4 / MP3 | オリジナル |
| ダウンロード速度 | 安定 / 標準 / 高速 | 標準 |
| ダウンロード画質 | 720p / 1080p / 最高画質 | 1080p |
| ダウンロード一覧 | 一覧ウィンドウの表示・非表示 | ダウンロード開始時に自動表示 |
| 全画面時に PIP を有効にする | 全画面を PIP ウィンドウに | オン |
| 拡張機能 | 広告ブロックのオン・オフ | オン |

表示言語は Windows の表示言語に従います（韓国語 → 韓国語、それ以外 → 英語）。
